# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies in the issues, pull requests, discussions and every other place the project lives, and to everyone who takes part — maintainers included.

In short: be kind and assume good faith; criticise code, not people; no harassment, insults or discrimination, in public or in private.

## Reporting

Report a conduct problem privately, the same way as a security issue: on the repository's **Security** tab, **Report a vulnerability**, with "Conduct" in the title. It reaches only the maintainers. A report about a maintainer is handled by the others, without that maintainer.

## What happens

A maintainer reads every report, keeps the reporter's identity private, and answers within 5 working days. In line with the Covenant's enforcement guidelines, the outcome can be a private warning, a public one, a temporary ban or a permanent one, and the person is told which rule was broken.
